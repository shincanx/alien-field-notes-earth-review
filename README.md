A deterministic Python program that writes one original line of plain text — a review of planet Earth left by an alien tourist — to /output/entry.txt. The review: five stars for the views, one star for the locals, who built a glowing rectangle showing them the whole universe, then use it to argue with strangers.

## Run it

```sh
python3 main.py
```
